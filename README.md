# open.mp Anti-Cheat GameMode Tests

Standalone interactive staging gamemode for exercising the public API of [yyouki/anticheat](https://github.com/yyouki/anticheat).

This repository is intentionally separate from the anti-cheat framework. It consumes the framework as a pinned build dependency and never writes to that repository.

The runnable gamemode and operator instructions are being bootstrapped. See the first implementation pull request for the compiled CI artifact and installation guide.
